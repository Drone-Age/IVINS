# Політика версіювання iVINS

## Версія продукту

`VERSION` має формат `PRODUCT.MAJOR.MINOR.PATCH`. Продуктовий тег має формат
`v<PRODUCT>.<MAJOR>.<MINOR>.<PATCH>`.

- `PRODUCT` — нове покоління продукту або нова матриця сумісності;
- `MAJOR` — несумісна зміна поведінки чи інтерфейсу кінцевого продукту;
- `MINOR` — зворотно сумісна функціональність або оновлення компонента;
- `PATCH` — зворотно сумісне виправлення чи перепакування.

Версія iVINS не дублює версії компонентів. Вона ідентифікує одну перевірену
матрицю точних Git commit, Debian-версій, артефактів і результатів gate.

## Версія процесу

`PROCESS_VERSION` використовує SemVer. Вона змінюється незалежно від версії
продукту:

- `MAJOR` — несумісна зміна manifest schema або обов’язкових gate;
- `MINOR` — нова сумісна перевірка чи автоматизація;
- `PATCH` — виправлення без зміни контракту процесу.

Тег процесу має формат `process-v<MAJOR>.<MINOR>.<PATCH>`. Якщо один change
змінює і продукт, і процес, змінюються обидва файли версій.

## Незмінність

Опубліковані Git-теги, manifests, checksums і native-gate evidence незмінні.
Дефектний випуск відкликається, але його версія не перевикористовується.
Виправлення отримує наступну продуктову версію та проходить усі gate повторно.
